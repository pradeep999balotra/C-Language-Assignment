## ▶️ How to Run the Programs

You can compile and run the programs using GCC and Visual Studio Code.

### Step 1: Clone this repository
`git clone https://github.com/pradeep999balotra/C-Language-Assignment.git`

### Step 2: Open the project folder
`cd C-Language-Assignment`

### Step 3: Compile a C program
For example:
`gcc assignment_01.c -o assignment_01`
*(Replace `assignment_01.c` with the name of the program you want to run.)*

### Step 4: Run the program
* On **Windows**: `.\assignment_01.exe`
* On **Linux**: `./assignment_01`

*Make sure GCC is installed and configured on your system before compiling the programs.*
